## 5. Design rules

- Black `#000` and brand yellow (sample the exact value from the PDF logo), white text. Poppins for text, bold italic for headings (same as the deck).
- **No pill-shaped buttons.** Rectangular buttons, 2–4 px radius, or the deck's slanted-edge look.
- **No purple, no gradients.** Flat black, flat yellow, the brush textures as images.
- Keep the brush streaks as accents only; they must not sit behind body text.
- Mobile first. Gutter 16 px. One column below 768 px.
- Text contrast at least 4.5:1. Real `<h1>`–`<h3>`, alt text on every photo, visible keyboard focus.

## 6. Tech

Static HTML + CSS, no framework, no build step. One small JS file for the mobile menu if needed. Host on any static host (Vercel, Netlify, GitHub Pages). **ASK** for a domain; `cmf.lv` or similar needs checking.

## 7. Copy rules ("un-AI")

- Short sentences. One idea each.
- No "grandioz", "unikāls", "viesmīlīgs", "harmoniski saplūst", no three-item flourishes, no "ne tikai… bet arī".
- Every claim carries a number, a name or a date, or it is cut.
- Say who does what: "Sponsors saņem…", "Mēs nodrošinām…".
- Latvian first; a native speaker reads it before it goes live.
